# Production design and release safeguards

- The approved September 20, 2026 design is orange (#F58220), DM Serif Display typography, light grey navigation, and the orange vector wordmark. Do not restore the older yellow brand theme.
- Preserve semantic stock colours: red below 50% of par, orange 50–74%, yellow 75–99%, green at or above par. These status colours are not brand colours.
- Before publishing, compare against the latest remote main and preserve every unrelated change. Never replace production files wholesale from an older worktree or deploy an old build to implement a feature fix.
- Run the design baseline check, tests and build before release. Never remove or weaken the design check to make an older design pass.
- Preserve invoice matching, newest-first invoice/order sorting, and demo scheduling access. Keep Clover sandbox changes isolated until explicitly approved for production.
